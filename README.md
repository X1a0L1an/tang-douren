# 🫘 糖豆人闯关 · Fall Beans

一个纯 HTML/Canvas 制作的「糖豆人」风格闯关小游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 🎮 玩法

控制可爱的糖豆人，穿过重重障碍，一路冲向终点线！

关卡障碍包括：

- 🔨 **旋转锤** —— 会被撞飞，注意时机躲开
- ⬆️ **升降块** —— 趁它落下时跳过去
- 🚪 **滑动门** —— 看准缺口起跳穿门
- 🛟 **横移浮板** —— 跳上去搭一段"顺风车"
- 🎯 **弹跳板** —— 高高弹起翻越高墙

❤️ **血量系统**：掉下深渊会扣除一颗爱心并回到最近的检查点；3 颗爱心用完则游戏结束。

## 🕹 操作

| 动作 | 按键 |
| --- | --- |
| 左右移动 | `←` `→` 或 `A` `D` |
| 跳跃 | `空格` / `W` / `↑` |
| 开始 / 重开 | `空格` / `回车` / `R`（或点击按钮） |

触屏设备会显示屏幕上的虚拟方向键。

## 🚀 运行

直接用浏览器打开 `index.html`，或在任意静态服务器下访问：

```bash
# 例如用 Python
python -m http.server 8000
# 打开 http://localhost:8000
```
